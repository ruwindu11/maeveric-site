// The platform difference

One approval. Multiple agents. Atomic commit.

Most AI tools run one task at a time. maeveric runs cross-agent workflows. A real business event triggers a chain of actions across domains. You approve the whole chain in one Teams card. The platform commits everything, or rolls back if any step fails.

Trigger

A bank deposit notice arrives in the finance mailbox. USD 24,800 from Contoso Manufacturing, against an overdue invoice.

Context

Contoso has a new order on credit hold. The overdue balance pushed them past their limit.

Finance Agent

Matches the payment. Proposes the cash application and clears the overdue flag.

Sales Agent

Sees the credit is restored. Proposes releasing the held order and notifying the account manager.

Outcome

One approval in Teams. Cash applied in Business Central. Held order released. Account manager notified. If any step fails, every prior step rolls back.

// Posting Control Model

AI proposes. You approve. maeveric executes.

No model writes to your ledger on its own. Every transactional step routes through a human approval inside Teams. Deterministic code commits. The LLM stays on the perimeter.

01

Propose

The agent matches your intent to a designed workflow. Parameters extracted from chat. Live data pulled from your ERP.

02

Approve

You see every step inside a Teams adaptive card. Customer, amounts, GL accounts. Approve once for the whole chain.

03

Execute

Deterministic code commits the saga. Failures trigger compensation across every prior step. The audit trail writes itself.

// Built for IT to approve

Tenant-native. Boring on the parts that matter.

maeveric deploys inside your Azure tenant. Your data never leaves it. Identity comes from your Entra. The orchestrator is deterministic by design. The LLM sits on the perimeter.

Stateless orchestrator, stateful context store

Saga via Azure Durable Functions. Shared context exposed through a versioned API with full audit, never via direct DB access.

Posting Control Model

GL accounts come from BC's posting setup at runtime. The LLM never memorises your chart of accounts. Every posting routes through a human approval.

Compensation across agents

Cross-agent workflows roll back as a unit. Finance posted but Sales failed? Finance reverses. The customer never sees a half-finished state.

Closed Phase 1, open by Year 2

Only maeveric agents run on the orchestrator today. The platform opens to third-party and Microsoft agents once the contract is hardened.
